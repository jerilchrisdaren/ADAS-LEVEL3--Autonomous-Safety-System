# ADAS-LEVEL3--Autonomous-Safety-System
Advanced ADAS Level 3 safety system with obstacle detection, automatic emergency braking, automatic steering intervention, lane-deviation detection, driver takeover, system limitation monitoring, and real-time safety status display.
## Project Overview

This project is an Arduino-based ADAS Level 3 safety system designed to improve vehicle safety by monitoring obstacles, lane deviation, driver takeover requests, system limitations, and vehicle speed.

The system provides multi-level safety responses, including warnings, automatic braking, and emergency steering intervention when a critical situation is detected.

## Key Features

- Front, left, and right obstacle detection
- Automatic emergency braking
- Automatic emergency steering
- Lane-deviation detection
- Driver takeover / manual mode
- System limitation monitoring
- Speed-based risk assessment
- LCD, LED, and buzzer safety indications

## Hardware Used

- Arduino Uno
- 3 × HC-SR04 Ultrasonic Sensors
- 2 × Servo Motors
- 16×2 I2C LCD
- Buzzer
- Green, Yellow, and Red LEDs
- Push Buttons
- Potentiometer
